支持与常见问题

下面这些问题覆盖了绝大多数使用场景。如果仍有疑问，可通过页面底部的支持入口反馈。

使用指南

01　导入与保存

支持照片选择器与系统文件导入 JPEG、PNG、HEIC，以及系统可解码的图像，单张上限 4800 万像素。原片单独保存，离开编辑或切到后台时自动保存参数。

02　精修工作台

风格控制整体气质，光色调整曝光与颜色，人像提供面部柔肤和补光。背景可虚化或换纯色底；局部画笔用于有选择地提亮、压暗、暖色、柔化和去色。

03　检查细节

点击原片对比查看相同构图下的修改，双击或双指放大预览。历史记录可以回到本次编辑的任意步骤；恢复原片同样可以撤销。

04　整组交付

作品页点「选择」再进入批量处理，可保留每张各自的修改或套用同一款光色风格；Mac 上生成完毕后点击「保存整组到文件…」选择目标文件夹；iPhone/iPad 可通过系统分享保存文件。

05　Mac 桌面操作

需要 macOS 15 或更新版本。左侧作品库侧栏切换作品、风格和设置；编辑时左侧预览，右侧显示九类工具。⌘O 从 Finder 导入，⌘Z / ⇧⌘Z 撤销与重做，⌘B 对比原片，⌘E 导出，⌘[ 保存并返回作品库。生成高清照片后，点击「保存到文件…」选择文件名与位置。

常见问题

Mac 与 iPhone/iPad 的作品会同步吗？

不会自动同步。各设备的作品库、调整参数与个人风格分别保存在本机。可先导出成片，再通过你选择的文件传输方式交付。

人脸工具是灰的，点不动？

说明这张照片没有检测到人脸。柔肤、补光与美型只在识别到人脸后才启用；多人合照中每一张人脸独立计算，互不影响。

界面提示「近似人物蒙版」是什么意思？

当系统人物分割能力不可用或分析未能生成有效蒙版时，应用会按人脸位置推算近似蒙版，并在界面标注。不同硬件、系统版本和照片可能得到不同结果。人脸关键点提示「近似关键点」表示使用了替代定位结果；请对照原片检查边缘与五官。

我的照片会被上传吗？

不会。所有处理都在设备本地完成，应用不含上传功能，也不需要联网。详见隐私政策。

卸载应用会丢失作品吗？

作品库保存在应用沙盒内。iPhone/iPad 删除应用会移除本地作品；Mac 将应用移到废纸篓不一定同时清除沙盒数据。重要作品请提前导出；需要删除作品时，可在应用内删除并清空「最近删除」。

导出是什么格式和色彩空间？

支持 JPEG、HEIC 与 PNG，输出为 8-bit sRGB，可设置原尺寸 / 4K / 2K / 1080 的上限与 DPI 元数据。JPEG 与 HEIC 为有损编码，PNG 为无损编码。导出不携带原片的 EXIF 与 GPS 信息。

支持 RAW 吗？

支持通过系统 RAW 解码进入统一调整管线，解码阶段会自动启用镜头校正与色域映射。目前没有独立的 RAW 高光恢复滑杆。

当前版本的能力边界

本版未接入生成式祛痘、衣物祛褶皱、身体塑形、天空替换与妆容迁移。柔肤是保守的区域平滑，背景虚化不是物理景深模拟，人物分离在发丝与透明材质等复杂边缘可能出现瑕疵，建议对照原片确认后再使用。
