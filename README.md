# 上架配套站点

三个页面，纯静态、无外部依赖、深色主题与 App 同源，可以直接扔到任何静态托管上。

```
site/
  index.html          落地页（把支持页和隐私政策串起来）
  privacy/index.html  隐私政策（App Store Connect 必填）
  support/index.html  支持与常见问题（App Store Connect 必填）
  styles.css          三页共用样式
```

## 一、先替换占位内容

两个页面里各有一处联系邮箱占位，搜索 `请替换为你的联系邮箱` 改成你的实际地址。没有邮箱也可以用你的域名邮箱，例如 `hello@yourdomain.com`。

## 二、部署

把 `site/` 目录整体上传到静态托管即可，三条路径分别对应：

| 用途 | URL |
|---|---|
| 隐私政策 URL | `https://你的域名/privacy/` |
| 支持 URL | `https://你的域名/support/` |
| 落地页 | `https://你的域名/` |

托管方式按方便程度排：

- **海外托管**（Cloudflare Pages、GitHub Pages、Vercel）：免费、几分钟上线、自带 HTTPS，不需要备案。缺点是国内访问偶尔不稳。
- **国内托管**（阿里云 OSS、腾讯云 COS、又拍云）：国内访问快，但**域名必须先完成 ICP 备案**才能绑定，备案周期一到三周。

## 三、和 App 备案的关系

App 在上架中国大陆区 App Store 时需要提供 APP 备案号，办理时要填主体信息和域名。如果站点用国内托管，域名备案这一道本来就要走，等于顺手一起办了；如果用海外托管，域名本身免备案，但 **App 备案仍需通过有资质的接入服务商单独办理**，两者不能互相替代。

## 四、填进 App Store Connect

| 字段 | 值 |
|---|---|
| 隐私政策 URL | `https://你的域名/privacy/` |
| 支持 URL | `https://你的域名/support/` |
| 营销 URL（可选） | `https://你的域名/` |

隐私政策页的正文与 App 内「设置 → 数据处理说明」的口径保持一致：不收集个人信息、照片不上传、无第三方 SDK、导出不携带 EXIF 与 GPS。以后如果任何一条发生变化，两个地方要同步改。
