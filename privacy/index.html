隐私政策

最后更新：2026 年 9 月 12 日　·　生效日期：2026 年 9 月 11 日

一句话版本

光影精修应用不收集你的个人信息，不会主动上传你的照片。本政策适用于 iPhone、iPad 与 Mac 版本。

一、我们不收集你的个人信息

光影精修不需要注册账号，不使用登录体系，不收集姓名、手机号、邮箱、设备标识符、位置信息或通讯录。应用内没有广告，也没有任何第三方统计、数据分析或广告 SDK。

二、你的照片不会被上传

所有图像处理——包括人脸检测、人脸关键点定位、人物分离、美型形变、背景虚化与光色调整——全部通过 Apple 的 Core Image 与 Vision 框架在你的设备本地完成。

应用不包含照片上传功能，不会将你的照片传输到任何服务器，也不会与任何第三方共享。应用可以完全离线使用。

三、我们申请的权限及用途

  • 选择照片或文件：通过系统照片选择器或文件面板导入，仅读取你主动选中的图像；Mac 通过系统面板访问你选择的文件与保存位置。
  • 添加到照片：仅在你导出作品并选择「保存到照片」时申请，用于写入你主动导出的成品图。

应用不申请相机、麦克风、定位、蓝牙与通讯录权限。

四、数据存储在哪里

  • 你的作品库、编辑参数、个人风格预设与最近删除记录保存在设备本地的应用沙盒目录中，应用不会主动同步到服务器，Mac 与 iPhone/iPad 作品库各自独立。你启用的系统备份或选择的云盘可能由相应系统服务处理。
  • iPhone/iPad 删除应用会移除其本地数据；Mac 删除应用不一定同时移除沙盒中的数据。请提前导出重要作品。你可以在应用内删除作品并清空「最近删除」。
  • 「清理缓存」只移除已生成的临时导出文件，不删除原片、编辑记录或个人风格；「最近删除」中的作品在恢复或永久删除前会继续占用本机空间。

五、关于照片中的个人信息

你导入的照片可能包含人像等个人信息。这些信息始终保存在你的设备上，由你独立控制。主动使用系统分享、保存到云盘或同步的系统照片图库时，数据传输由你选择的目标服务处理。导出时，应用默认不写入原片的 EXIF 与 GPS 信息，因此分享出去的成片不会携带拍摄地点等元数据。

六、儿童

光影精修不面向儿童收集任何个人信息，也不提供社交、发布或用户间互动功能。

七、第三方组件

应用仅使用 Apple 官方系统框架（SwiftUI、Core Image、Vision、PhotosUI、ImageIO），不集成第三方统计或广告服务。支持网站托管于 GitHub Pages，公开支持请求由 GitHub Issues 提供；主动访问这些网站时，适用 GitHub 的隐私政策。你通过支持渠道主动提交的信息仅用于处理相应问题，请勿提交私人照片或敏感个人信息。

八、政策更新

本政策如有修改，我们会更新本页顶部的日期。涉及数据处理方式的重大变更，会在应用更新说明中一并告知。

九、联系我们

如对本政策有疑问，可通过支持入口联系我们。该入口为公开页面，请只描述问题，不提交敏感个人信息。
